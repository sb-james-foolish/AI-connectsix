## 优先级建议

### 第一阶段：把现有体验做扎实

1. 热力图继续补强
2. 机器人双子协同推荐更稳定
3. 大模型输出更贴近棋手语言
4. 时间序列复盘加入关键分叉解释

### 第二阶段：做“能看懂”

1. 热点悬浮详情
2. 推荐点为什么强的逐条解释
3. 复盘里展示“这手若改下哪里会更好”
4. 用户画像加入最近 10 局趋势

### 第三阶段：做“能扩展”

1. 多 Agent 分析
2. 自我对弈生成训练数据
3. 更强的知识图谱交互
4. 机器人强度分级

## 推荐落地顺序

1. 热力图与推荐质量
2. 复盘解释质量
3. 用户画像与训练建议
4. 多 Agent 分析
5. 自我对弈数据

## 多 Agent 的最小版本

如果后面要上多 Agent，建议先做轻量版，不要一开始就做复杂编排：

- `attack_agent`：只负责找我方最强进攻点和双线点
- `defense_agent`：只负责找对手下一手最危险点
- `coach_agent`：把前两者结果翻译成人能看懂的话

这样可以先把架构立住，再决定是否真的接大模型并行调用。
